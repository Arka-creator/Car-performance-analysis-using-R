# Car Performance Analysis Using R

## 📌 Project Description

This project analyzes car performance data using the built-in **mtcars dataset** in R.

The analysis includes mileage, horsepower, weight, cylinders, and transmission type.

##  Features

* Dataset exploration using `head()`, `tail()`, `str()`, and `summary()`
* Calculate average mileage and horsepower
* Find the most and least powerful cars
* Find cars with highest and lowest mileage
* Find the heaviest and lightest cars
* Calculate correlation between horsepower and mileage
* Generate different visualizations

## Visualizations

* Horsepower vs Mileage
* Weight vs Mileage
* Mileage Distribution
* Average Mileage by Cylinder
* Average Mileage by Transmission

## Technologies Used

* R Programming
* Built-in `mtcars` Dataset

## Output

All generated graphs are saved automatically in the **plots** folder.

## Conclusion

This project demonstrates basic data analysis and visualization in R using the `mtcars` dataset.
